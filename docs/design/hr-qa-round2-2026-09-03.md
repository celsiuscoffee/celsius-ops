# HR module — flow + codebase QA, round 2 (2026-09-03)

Owner: "lets do qa (flow and code base) for hr module". Round 1
(`hr-flow-qa-2026-09-03.md`) inventoried the module and fixed the review
queue. This round read the code of every HR slice against the business rules
and the Malaysian statutory rules, and checked the live August/September data
for the same failure classes. Five reviewers in parallel (attendance/OT,
leave/scheduling, payroll/statutory, people/access, staff-facing apps), every
finding verified against the source before it was fixed.

Status legend: **Fixed** = in PR `claude/hr-qa-round2`. **Owner** = needs a
decision or data action. **Backlog** = real, not fixed here (bigger change or
native app OTA).
