## The review flow now

One queue, one decision, no second entry point.

- **Attendance Review** (`/hr/attendance`) opens on *Needs review · last 30 days*.
  Filters: period preset or custom range · outlet · staff · one flag · "With OT".
  Rows are grouped by day; each row shows rostered vs actual, lateness, flags,
  the OT the approval would pay (or the "fix times" warning), location and
  selfies on expand. Tick rows → **Approve + Nh OT / Excuse / Reject** in one
  request; single-row buttons remain. Approving the day files the approved OT
  request (unchanged rule from #1210).
- **Overtime** (`/hr/overtime`) is the ledger: what was approved this month,
  per person, with the clock-ins behind each line; plus the two non-clock
  sources (staff pre-approval requests, manager "Unclocked OT"). Nothing syncs
  from attendance here any more.
- **Leave** opens on what needs a decision; the dashboard tile counts it.

## HR module IA (proposal, not built)

Keep the six BrioHR-style modules but make the tab strip the only sibling
navigation, generated from `nav.tsx`:

| Module | Tabs |
|---|---|
| People | Employees · PT Rates · App Access · Certifications · Memos |
| Time | **Review** (attendance + OT decisions) · Overtime ledger · Roster vs actual · PT Hours · Shift Swaps |
| Leave | Requests · Balances · Policies · Public Holidays |
| Scheduling | Schedules · Availability · Coverage |
| Payroll | Monthly · Weekly · Allowances · Statutory Calendar |
| Performance | Scores · Review Penalties |

Settings stays a separate section. `/hr/allowances` (read-only), `/hr/settings/allowances` (pool rules) and `/hr/settings/staff-allowances` (flat per person) should collapse into one page with two tabs once the profile input (finding 5) has been live for a month.
