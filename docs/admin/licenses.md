# Licences & permits — per outlet

Every licence/permit each outlet needs to operate legally. Every row with an
expiry also gets a row in `renewals.md`.

Typical Malaysian F&B set per outlet (delete what doesn't apply, add what
does): premise/business licence (local council), signboard licence, food
handler certificates (staff) + typhoid vaccination, halal certification
(JAKIM) if pursued, music licence (PPM / MACP / PRISM) if playing music,
fire safety (Bomba) requirements. LHDN/e-invoice is in `compliance.md`.
