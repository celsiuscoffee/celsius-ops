# Admin — business administration hub

Home for everything "admin" about running Celsius Coffee that is not code:
company registration, licences and permits, tenancy, insurance, vendor
contracts, and statutory compliance. This folder is the **index and tracker**;
the actual documents (scans, agreements, certificates) live in Google Drive —
each entry here links to its Drive file.

## What lives where

| File | Covers |
| --- | --- |
| `renewals.md` | **Master deadline tracker** — every renewal/expiry across all domains, sorted by due date. The one file to check monthly. |
| `company.md` | Entity registration (SSM), directors/shareholding, company secretary, bank accounts. |
| `licenses.md` | Per-outlet licences & permits — premise licence, signboard, food handler, halal, music, fire cert. |
| `outlets.md` | Tenancy agreements, landlord contacts, utility accounts per outlet. |
| `insurance.md` | All policies — fire, burglary, public liability, group PA. |
| `contracts.md` | Vendor and service contracts with terms and notice periods. |
| `compliance.md` | Statutory/tax — LHDN, SST, e-invoice, EPF/SOCSO/EIS employer registrations. |

## Rules

1. **No secrets or full documents in this repo.** Mask account numbers to the
   last 4 digits; never commit IC copies, statements, or signed agreement
   scans — link the Drive file instead.
2. **Every dated obligation gets a row in `renewals.md`** in addition to its
   home file. `renewals.md` is the only file that must be complete.
3. **Date every entry** (`2026-08-31 —`) the same way `docs/STATE.md` does, so
   stale info is visible.
4. Payroll-adjacent admin (EPF/SOCSO submissions, payslips) is handled by the
   HR module — see `docs/hr-payroll-spec.md`. `compliance.md` only records the
   employer registrations and who is responsible.

## Brands / entities

Celsius Coffee and BERBUKA@CELSIUS are tracked as separate brands; if they sit
under separate entities, each gets its own section in `company.md`.
