# Gosame manual (GS-)

Not started. Gosame is a separate business entity with its own infrastructure
(the `gosame-ops` Supabase project exists since 2026-07-10).

To start this manual:

1. Owner describes the business → set the domain map (may differ from
   Celsius's F&B chapters; see `docs/sop/README.md`).
2. Copy the framework as-is: same `TEMPLATE.md`, same rules
   (`CC-GOV-001 Document Control` applies verbatim under a `GS-GOV-001`
   adoption document), `GS-` prefix, own sections in `REGISTRY.md`.
3. Decide with the owner whether any functions are shared with Celsius in
   practice (finance/HR) — if yes, those documents move to the `GRP-` prefix.

System integration (staff-app reader, acknowledgments) for Gosame staff is
phase 3 — it requires the multi-tenant auth/RLS work described in
`docs/design/sop-module.md`. Until then, GS documents ship as exported PDFs.
